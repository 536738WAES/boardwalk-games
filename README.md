# Boardwalk Games

Front-end website for a fictional tabletop games shop and cafe.

## Business goals
- Primary: increase in-store foot traffic and customer engagement
- Showcase shop services
- Increase brand awareness
- Provide essential information
- Encourage group visits and events

## User personas
- Casual gamers
- Board game enthusiasts
- Student gamers

## User stories
User stories, acceptance criteria and tasks are tracked on the [GitHub Project board](https://github.com/users/536738WAES/projects/6).

| # | User story | Persona | Priority |
|---|---|---|---|
| 1 | User friendly navigation and responsive design | First-Time Visitor | Must have |
| 2 | High quality images and engaging descriptions | Casual Gamer | Must have |
| 3 | Location, contact details and opening hours | Prospective Customer | Must have |
| 4 | Booking inquiry form | Customer | Must have |
| 5 | Visible pricing for events and student discount | Student Gamer | Should have |
| 6 | Testimonials | Prospective Customer | Could have |
| 7 | Newsletter sign up form | Regular Customer | Could have |
| 8 | Game Library page | Board Game Enthusiast | Must have |
| 9 | Game reservation form | Board Game Enthusiast | Should have |
